## Data flow (unchanged)

- TOML vanompp.toml parse_ports skip malformed -> Option ports -> effective = persisted ?? default
- loadPersistedFromRust merges TOML -> localStorage + store
- refreshStatus reads getEffectivePorts
- Start flow checkPorts -> PortInfo free suggest_next_free -> conflict dispatch -> modal -> Tetap pakai persist via setPersistedPort atomic_write tmp.{pid}.{nanos} rename -> store update -> startService -> refreshProjects if apache
- scan_projects_with_port builds http://localhost:{port}/{file}

Known ceilings documented ponytail comment for future:
- atomic_write RMW race apache+mysql concurrent overwrite other key -> low risk single user, upgrade file lock if need
- suggest_next_free scans 20 only fallback same start if 20 busy -> upgrade bigger range or error if dense
- toConflicts hardcode 3306->mysql heuristic -> upgrade index mapping
- toast double timer App 5500 + Toast 4000 -> single source Toast auto after fix
